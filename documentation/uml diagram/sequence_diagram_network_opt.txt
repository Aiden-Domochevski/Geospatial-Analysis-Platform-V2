== Étape 1: Configuration Initiale ==

User -> Dash: 1. Accéder à l'onglet\n"Optimisation du Réseau"
Dash --> User: 2. Afficher les paramètres\nde seuils (Sur/Sous-performance)
User -> Dash: 3. Ajuster les seuils\nd'analyse

== Étape 2: Modélisation et Évaluation ==

User -> Dash: 4. Lancer l'optimisation
Dash -> Dash: 5. Afficher état d'avancement
Dash -> Data: 6. Charger les données\nexistantes et de performance
Data --> Dash: 7. Retourner données unifiées
Dash -> Eval: 8. Entraîner le modèle\nd'évaluation financière
Eval --> Dash: 9. Retourner le modèle entraîné
Dash -> Eval: 10. Prédire le revenu attendu\npar agence
Eval --> Dash: 11. Retourner les revenus prévus
Dash -> Eval: 12. Calculer le ratio de performance\n(Réel / Attendu)
Eval --> Dash: 13. Retourner les ratios

== Étape 3: Catégorisation Stratégique ==

Dash -> Strat: 14. Classer les agences\n(Matrice Stratégique)
Strat --> Dash: 15. Retourner les catégories\n(Excellence, À revoir, Fermer...)
Dash -> Spatial: 16. Identifier les agences à fermer\nou à revoir
Spatial --> Dash: 17. Retourner liste filtrée
Dash -> Spatial: 18. Vérifier la proximité avec\nune agence d'excellence
Spatial --> Dash: 19. Retourner fusions suggérées
Dash -> Strat: 20. Mettre à jour les recommandations\navec les fusions
Strat --> Dash: 21. Retourner recommandations finales

== Étape 4: Restitution et Export ==

Dash --> User: 22. Afficher la matrice stratégique\n(Potentiel vs Exécution)
Dash --> User: 23. Afficher la carte de restructuration\nspatiale
Dash --> User: 24. Afficher le tableau des\nrecommandations actionnables
Dash --> User: 25. Proposer le téléchargement\ndes données d'optimisation
